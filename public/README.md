# БУНКЕР: ЕКОНОМІКА · ONLINE

Готова багатокористувацька гра в браузері. Ведучий створює кімнату, надсилає посилання або код, кожен студент приєднується зі свого телефона та бачить **лише власні секретні картки**.

## Що вже працює

- Створення кімнат із шестизначним кодом і посиланням-запрошенням.
- Від 1 до 8 команд та до 20 гравців у кожній кімнаті **загалом**.
- Вибір від 1 до 8 випадкових категорій кожному гравцю.
- Усі оригінальні 176 карток: професія, біологія, здоров'я, хобі, багаж, два факти та особливий випадок.
- Серверна роздача: **чужі закриті картки не передаються** браузеру. Навіть ведучий бачить лише відкриті.
- Розкриття по одній картці з миттєвим оновленням усіх підключених екранів (SSE).
- Раунди, виключення / повернення гравців, закінчення гри, нова роздача.
- Ведучий може створювати команди, змінювати назви, переносити учасників, примусово відкривати / приховувати, міняти та обмінювати картки.
- «Особливі випадки» відмічаються як використані. **Ефекти та голосування виконуються за домовленістю учасників, не автоматично**.
- Після перезавантаження сторінки роль ведучого / учасника зберігається **на тому самому пристрої та в тому самому браузері**, доки існує кімната на сервері.
- На сервері ведеться історія використаних карт; при нових роздачах вибираються найменш використані, уникаються повтори для тієї самої людини (якщо є можливість). У межах партії 20 учасників отримують різні картки кожної категорії.

> Усього 20 карток у найменших категоріях. При 20 гравцях із усіма 8 категоріями наступна партія неминуче знову використовує ті самі 20 карток у кожній такій категорії, проте система перерозподіляє їх між людьми.

## Запуск на своєму комп'ютері (Windows / Mac / Linux)

1. Встанови [Node.js](https://nodejs.org/) версії **20 або новішої**.
2. Розпакуй ZIP, відкрий термінал / PowerShell у папці `bunker_online`.
3. Запусти `npm start` (або `node server.js`). **Нічого додатково встановлювати не потрібно**, сторонніх пакетів немає.
4. Відкрий `http://localhost:3000` у браузері.
5. Для участі телефонів **в одній Wi-Fi мережі** відкрий сайт за LAN-адресою комп'ютера, наприклад `http://192.168.1.10:3000`. Для цього може знадобитися дозволити порт 3000 у брандмауері Windows.

`localhost` працює тільки на власному комп'ютері — для друзів поза Wi-Fi потрібне розміщення на публічному сервері.

## Як отримати справжнє публічне посилання (Render)

1. Створи **новий репозиторій GitHub** і завантаж у корінь файли з цієї папки: `server.js`, `deck.js`, `package.json`, `render.yaml`, папку `public` тощо. Не завантажуй папку `data` із реальними кімнатами.
2. Відкрий [dashboard.render.com](https://dashboard.render.com/) → **New → Web Service** → підключи свій репозиторій GitHub.
3. Вибери **Language: Node**, **Build Command: `npm install`**, **Start Command: `npm start`**, **Health Check: `/api/health`**. План Free підійде для тестової гри.
4. Натисни **Deploy**. Після завершення Render надасть адресу вигляду `https://назва-проєкту.onrender.com`.
5. Ведучий відкриває **саме цю адресу**, створює кімнату й надсилає гравцям кнопку «Запросити». Посилання матиме вигляд `https://назва-проєкту.onrender.com/?room=ABC123`.

Важливо: створюй саме **Web Service**, а не Static Site / GitHub Pages, оскільки секретні картки й синхронізацію обробляє сервер.

### Надійність збережень

- За замовчуванням стан усіх кімнат і історія використання карт зберігаються в `data/state.json` на сервері.
- **Безкоштовний Render не має постійного диска**. Після перезапуску, redeploy або переходу безкоштовного сервісу в сон дані кімнат можуть зникнути. За простого тестування це нормально, але **під час офіційного заходу не покладайся на збереження на Free**.
- Для надійного тривалого хостингу обери paid Web Service з Persistent Disk: монтуй його до `/var/data` і встанови змінну середовища `DATA_FILE=/var/data/state.json`.
- Для одноразового заходу без оплати можеш тримати сервер на власному комп'ютері, а доступ через інтернет організувати окремо (тунель або публічний сервер); сам ZIP не створює зовнішньої адреси.

## Структура

- `server.js` — HTTP API, авторизація, синхронізація SSE, роздача та збереження;
- `deck.js` — усі 176 карток (на сервері; браузеру не віддається);
- `public/` — адаптивний інтерфейс для ведучого й телефонів учасників;
- `render.yaml` — конфігурація для Render Blueprint;
- `test/rooms.test.js` — автоматизовані перевірки.

## Перевірка

Запусти `npm test`. Перевіряються: оригінальна колода, авторизація, приватність карт, команда/раунди, 20 гравців без повторів усередині категорії та отримання live-оновлень.

## Умови

- Секретний ключ ведучого зберігається в локальному сховищі браузера, **не** в URL. Не передавай іншим доступ до свого браузера або локального сховища.
- Кожен учасник має відкривати сайт на своєму пристрої / в окремому браузерному профілі. Сайт не є системою з персональними обліковими записами.
- Якщо хочеш сам брати участь у грі як ведучий, відкрий запрошення у другому браузері або на іншому пристрої.
- Акаунти, чат, автоматичне голосування і повне автоматичне застосування особливих карт поки не реалізовані.
